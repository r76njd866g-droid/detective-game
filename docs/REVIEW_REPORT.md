## Что требует ручной приёмки

Firefox, Safari/iOS, реальные устройства Android, звук, screen reader, удобство касаний и визуальная оценка служебных ссылок. Нужна проверка настоящих сохранений добровольно предоставленного тестового профиля старой версии: автоматические проверки используют синтетические данные. Редактору следует подтвердить сюжетные тексты и оба эпилога.

## Ограничения и безопасные решения

- Старый формат не хранит принадлежность глав к прохождениям. Миграция сохраняет исходные строки и создаёт обозначенные восстановленные группы по ветке; неопределённость не скрывается.
- При точной одновременной записи `localStorage` не предоставляет транзакции. Независимые версии сохраняются отдельными ключами и доступны в списке; обычный конфликт обнаруживается до записи и создаёт отдельный путь.
- История расходует квоту браузера. Автоматическая очистка отключена. При отказе записи показано предупреждение; аварийный экспорт включает состояние из памяти.
- Импорт при нехватке места может добавить только часть новых путей. Прежние данные неизменны; удаление для освобождения места не выполняется.
- При смене адреса нужен экспорт с прежнего origin и импорт на новый. Откат к старому HTML читает только v1, поэтому новый прогресс перед откатом нужно экспортировать.
- Новая схема сценариев — техническая спецификация, не подключённый движок. Новые расследования, допросы, доска и технологии эпох не реализовывались.

## Как проверить и восстановить

Рабочую ветку запускать локально согласно README и `docs/TESTING.md`. Формат сохранений и ограничения описаны в `docs/SAVE_FORMAT.md`; следующий архитектурный этап — в `docs/ENGINE_PLAN.md`.

Из полного bundle можно создать отдельную проверочную копию:

```sh
git clone detective-game.bundle detective-game-review
cd detective-game-review
git switch fix/safe-playthrough-saves
python -m http.server 8080
```

Для проверки исходной версии создать отдельную ветку от тега, не сбрасывая рабочую ветку:

```sh
git switch -c review-original baseline-before-save-protection-20261022
```

Окончательное решение о слиянии и публикации остаётся за владельцем проекта. Эти действия не выполнены.
