# Проверки и локальный запуск

Из корня репозитория:

```sh
node tests/saves.test.js
python tests/static_check.py
python tests/browser_check.py
```

Первые две команды не требуют сторонних пакетов. Браузерный сценарий использует Playwright для Python и Chromium как инструменты разработки, без изменения зависимостей игры. В рабочей среде они уже доступны. В другом окружении их устанавливают отдельно; путь браузера можно передать через `CHROMIUM_PATH`. Тест поднимает временный HTTP-сервер на свободном loopback-порту, создаёт изолированные браузерные контексты и не обращается к действующему сайту. Выгрузки и результаты находятся в игнорируемом `work/`.

`node tests/saves.test.js` выводит результаты 18 предметных проверок, включая миграцию, обе ветки, повторное прохождение всех глав, повреждения, импорт/экспорт, конфликт вкладок, строго одновременные версии, недоступность и переполнение хранилища, соответствие метаданных существующему контенту.

Дополнительно: `python tests/spec_check.py` проверяет обе документирующие JSON Schema и файлы экспорта, созданные браузерным сценарием. Использует уже установленный инструмент разработки `jsonschema`; игра от него не зависит. В игровую поставку зависимости не добавлены.

`static_check.py` сравнивает контрольные суммы HTML вне script, CSS, встроенных изображений, сценарных данных и строк основных сюжетных функций с исходным тегом. Манифест `tests/baseline.json` сформирован из нетронутого исходного коммита. Разрешено добавление двух внешних скриптов и служебных ссылок на сохранения во время исполнения. Сравнение не доказывает визуальную идентичность на каждом устройстве, но защищает исходные ресурсы и содержание от незаметного изменения.

Браузерный сценарий проходит через реальные кнопки и формы: II–VIII на двух маршрутах, сбор и перечитывание документов, ошибочные и правильные выводы/ответы, перезагрузки, две операции склада, два эпилога, повтор главы V, возврат к развилке, экспорт/импорт в другой контекст, прямой вход всех глав на настольном и мобильном размерах, миграцию, предупреждение о повреждении и две вкладки. Первая глава не проверяется: её нет в этой версии.

## Ручная приёмка

- Firefox, Safari/iOS и реальные Android-устройства; режим private browsing и запрет хранения.
- Звук дождя, реальные касания, масштабирование, экранные клавиатуры и screen reader.
- Полное прохождение на реальном телефоне, включая попадание в активные области и длинные тексты.
- Визуальная оценка добавленных ссылок «Сохранения» и служебной страницы, особенно узкого заголовка.
- Экспорт из настоящего профиля старой опубликованной версии, импорт на тестовом origin, сверка пользователем своего прогресса. Тесты используют синтетические сохранения и не читают данные реальных игроков.
- Проверка редактором двух эпилогов и отсутствия сюжетных изменений.

Открывать игру: `python -m http.server 8080`, затем `http://localhost:8080`. Не публиковать до приёмки. Работа в `file://` не входит в поддерживаемый путь сохранений.
